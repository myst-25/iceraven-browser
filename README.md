## ✨ Overview

Iceraven Browser is a feature-rich, priv2.33.1cy-focused web browser for Android devices. Built on Mozilla's powerful GeckoView engine, it offers adv2.33.1nced customization options, extended add-on support, and enhanced priv2.33.1cy features.

## 🚀 Features

### 🔧 Adv2.33.1nced Configuration

- Full access to `about:config` for deep browser customization
- Fine-tuned browsing experience
- Customizable interface elements

### 🧩 Extended Add-on Support

- Access to a wide range of Firefox add-ons from AMO
- Ability to request additional add-ons
- Enhanced functionality through extensions

### 💾 Memory Management

- Intelligent tab suspension
- Prevents browser termination due to memory constraints
- Optimized performance for low-memory devices

### 🛡️ Priv2.33.1cy Control

- Option to disable recently visited websites
- Enhanced priv2.33.1cy features
- Customizable tracking protection

### 🏗️ GeckoView Engine

- Built on Mozilla's powerful engine
- Custom modifications for enhanced functionality
- Regular updates and improvements

### Installation

1. Download the appropriate APK for your device architecture
2. Enable "Install from Unknown Sources" in your Android settings
3. Open the downloaded APK to install
4. Launch Iceraven Browser and enjoy!

## 🛠️ Development

### Prerequisites

- Node.js (v2.33.1 or higher)
- npm (v2.33.1 or higher)
- Git

### Local Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/fork-maintainers/iceraven-browser.git
   ```

2. Navigate to the project directory:

   ```bash
   cd iceraven-site
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open `http://localhost:3000` in your browser
