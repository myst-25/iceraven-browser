Powerful Features

Iceraven Browser brings advanced capabilities and customization options to your Android device

Advanced Configuration

Full access to about:config for deep browser customization and fine-tuning of your browsing experience.

Extended Add-on Support

Access to a wider range of Firefox add-ons from AMO, with the ability to request additional add-ons.

Memory Management

Tab suspension feature to prevent browser termination due to memory constraints, ensuring smoother performance.

Privacy Control

Option to disable recently visited websites on the homepage for enhanced privacy.

GeckoView Engine

Built on Mozilla's powerful GeckoView engine with custom modifications for enhanced functionality.

Development Status

Currently in alpha stage with automatic GitHub releases. Perfect for users comfortable with experimental software.
