## ✨ Overview

Iceraven Browser is a feature-rich, privacy-focused web browser for Android devices. Built on Mozilla's powerful GeckoView engine, it offers advanced customization options, extended add-on support, and enhanced privacy features.

## 🚀 Features

### 🔧 Advanced Configuration

- Full access to `about:config` for deep browser customization
- Fine-tuned browsing experience
- Customizable interface elements

### 🧩 Extended Add-on Support

- Access to a wide range of Firefox add-ons from AMO
- Ability to request additional add-ons
- Enhanced functionality through extensions

### 💾 Memory Management

- Intelligent tab suspension
- Prevents browser termination due to memory constraints
- Optimized performance for low-memory devices

### 🛡️ Privacy Control

- Option to disable recently visited websites
- Enhanced privacy features
- Customizable tracking protection

### 🏗️ GeckoView Engine

- Built on Mozilla's powerful engine
- Custom modifications for enhanced functionality
- Regular updates and improvements

## 🛠️ Development

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)
- Git

### Local Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/fork-maintainers/iceraven-browser.git
   ```

2. Navigate to the project directory:

   ```bash
   cd iceraven-site
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open `http://localhost:3000` in your browser
