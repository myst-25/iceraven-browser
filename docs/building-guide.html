Prerequisites

Required Software

  • Android SDK (latest version)
  • Java JDK 11 or later (not Ubuntu Java 8)
  • Git
  • Android SDK Command Line Tools

Environment Setup

Setting Up Your Development Environment

First, set up your environment variables:

# Where does our system install the JDK? This is the right path for the Ubuntu Java 11 JDK
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
# Where did we install the Android SDK?
export ANDROID_SDK_ROOT=$HOME/android-sdk/android-sdk-linux/

Installing Android SDK on Linux:

mkdir -p $HOME/android-sdk/android-sdk-linux
cd $HOME/android-sdk/android-sdk-linux
mkdir -p licenses
echo "8933bad161af4178b1185d1a37fbf41ea5269c55" >> licenses/android-sdk-license
echo "d56f5187479451eabf01fb78af6dfcb131a6481e" >> licenses/android-sdk-license
echo "24333f8a63b6825ea9c5514f83c2829b004d1fee" >> licenses/android-sdk-license
mkdir cmdline-tools
cd cmdline-tools
wget "$(curl -s https://developer.android.com/studio | grep -oP "https://dl.google.com/android/repository/commandlinetools-linux-[0-9]+_latest.zip")"
unzip commandlinetools-linux-*_latest.zip
cd ..

Building Steps

Step-by-Step Build Process

  1. Clone the repository: 
    git clone --recursive https://github.com/fork-maintainers/iceraven-browser
  2. Navigate to the project directory: 
    cd iceraven-browser
  3. Configure the project:

    For personal use, you can use the debug key that is auto-generated by Android SDK:

    echo "autosignReleaseWithDebugKey=" >> local.properties
  4. Build the project:

    To build the Iceraven-branded release APKs:

    ./gradlew app:assemblefenixForkRelease -PversionName="$(git describe --tags HEAD)"

The APKs will be generated in app/build/outputs/apk/fenix/forkRelease/

Troubleshooting

Common Issues and Solutions

  • Build System Can't Find objcopy:

    Make sure to use the app: prefix in the gradle command as shown in the build steps.

  • Linter Errors:

    If you're getting errors from ./gradlew ktlint, try running:

    ./gradlew ktlintFormat
  • Memory Issues:

    If you encounter memory-related build issues, try increasing the memory available to Gradle by adding to gradle.properties:

    org.gradle.jvmargs=-Xmx4g
